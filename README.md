# My Personal Works

A collection of personal projects, applications, and experiments.

## Projects

### 📸 [Image Compressor](./Image%20Compressor)
An Android application for compressing and processing images efficiently using native code (libjpeg-turbo / C++ NDK) and Kotlin Jetpack Compose.
- **Platform**: Android
- **Tech Stack**: Kotlin, Jetpack Compose, Android NDK, CMake, libjpeg-turbo

### 🖥️ [Overlay Customization](./Overlay%20Customization)
A Windows desktop application for screen overlay customization with interactive graphics, animations, and custom styling.
- **Platform**: Windows
- **Tech Stack**: Python, PyQt6, ctypes, PyInstaller, Inno Setup

### 🎙️ [SpeakDo - On-Device Voice Note & Action Item Logger](./SpeakDo)
A 100% offline, privacy-first mobile application that captures voice notes or imported audio/video, transcribes on-device with whisper.cpp, extracts structured action items and deadlines using deterministic offline NLP, and syncs directly to the native phone calendar. Includes precompiled Android release APK.
- **Platform**: Android / Cross-Platform (Mobile, Desktop, Web)
- **Tech Stack**: Flutter, Dart, SQLite (sqflite / FFI), whisper.cpp, FFmpeg, Android NDK
- **Download APK**: [SpeakDo.apk](./SpeakDo/SpeakDo.apk)
